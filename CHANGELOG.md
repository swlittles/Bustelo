# Changelog

## 1.1.0

- Automatic updates. Bustelo checks GitHub once a day for signed, notarized releases. A new version shows as a dot on the cup and an "Update to Bustelo…" item in the menu, and you choose when to install it.
- Check for Updates… and Check for Updates Automatically in the menu.
- A running session resumes after Bustelo relaunches to install an update.

## 1.0.0

- Menu-bar app that keeps your Mac awake indefinitely or for 15 minutes to 8 hours.
- Keeps Teams and Slack from marking you Away. After 60 idle seconds it sends a no-op modifier event, so nothing is clicked, typed, or moved.
- Never nudges while the screen is locked, the display is asleep, the screen saver is running, a mouse button is held, or another user is active.
- Turn On When Bustelo Opens and Open at Login.
